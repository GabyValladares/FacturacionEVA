# Invoicing & Billing System (MVC Architecture) 📄

## Overview
A Java desktop application developed to simulate a complete billing and invoicing system. This project was built to practice software architecture patterns, specifically **Model-View-Controller (MVC)**, and relational database management with MySQL.

## Key Concepts & Architecture
* **MVC Pattern:** Clean separation between data models, business logic controllers, and graphical user interfaces (GUI).
* **Git Branching Workflow:** Feature development and module integration managed via Git branches (`hafit_branch`).
* **Relational Database Design:** Structured MySQL database for customer data, product catalogs, and invoice generation.

## Tech Stack
* **Language:** Java
* **Architecture:** Model-View-Controller (MVC)
* **Database:** MySQL
* **Version Control:** Git & GitHub
